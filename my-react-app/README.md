# Beibarys Arystanbekuly

A JavaScript React app displaying Beibarys Arystanbekuly's name and photo, without CSS.

The app uses three components: App, ProfileName, and ProfilePhoto.

## Run locally

From the repository root:

```sh
cd my-react-app
npm ci
npm run dev
```

## Checks

```sh
npm run lint
npm run build
```
